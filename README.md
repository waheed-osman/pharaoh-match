# ألغاز الفراعنة (Pharaoh Match)

لعبة ألغاز ومطابقة ثلاثية (3-Match) بالرموز المصرية القديمة، مكتوبة بـ Flutter
فتعمل على أندرويد وiOS من كود واحد.

## ما تتضمنه اللعبة

- **6 رموز مرسومة بالكود**: الجعران، مفتاح الحياة، عين حورس، المسلة، زهرة اللوتس، الهرم.
  لا توجد صور أو ملفات صوت، فالحزمة صغيرة وتحميلها سريع.
- **40 مستوى في 5 مراحل** (ضفاف النيل، معبد الكرنك، أهرامات الجيزة، وادي الملوك، حجرة الكنز).
  تزيد الصعوبة بثلاثة عوامل: عدد أنواع الرموز (4 ثم 5 ثم 6)، نقص عدد الحركات،
  وارتفاع النقاط المطلوبة. وكل ثلاثة مستويات يُضاف هدف جمع رمز معيّن.
- **سلاسل (Combos)**: كل تطابق متتالٍ يضاعف النقاط، وتسلسل 4 رموز فأكثر يعطي مكافأة.
- **نظام تلميحات ذكي**:
  - زر التلميح (3 مرات في كل مستوى) يحسب كل الحركات الممكنة ويختار الأفضل،
    مع تفضيل الحركة التي تجمع رمز الهدف، ويضيء الرمزين ويشرح الفائدة.
  - إن بقي اللاعب ساكناً 8 ثوانٍ يظهر تلميح مجاني تلقائياً.
  - إن انعدمت الحركات الممكنة تُخلط اللوحة تلقائياً.
- **مشهد المومياء**: عند نفاد الحركات تظهر المومياء من العتمة وتتقدم نحو اللاعب
  حتى تملأ الشاشة (مع وميض واهتزاز)، ثم تظهر لوحة "لعنة الفراعنة" لإعادة المحاولة.
- **حفظ التقدم** (المستويات المفتوحة والنجوم) محلياً.

## الأداء

- كل الرسوم تُرسم بالكود (`CustomPainter`) بلا أصول خارجية.
- كل بلاطة داخل `RepaintBoundary` ولا تُعاد رسمها إلا إذا تغيّر نوعها أو حالتها.
- حركة التلميح تعمل فقط أثناء ظهور تلميح، فلا يوجد رسم مستمر يستهلك البطارية.
- بناء أندرويد بالأمر `--split-per-abi` ينتج ملف APK أصغر لكل نوع معالج.

## هيكل المشروع

```
lib/
  main.dart            نقطة البداية (واجهة عربية RTL، اتجاه عمودي)
  theme.dart           ألوان مصر القديمة
  progress.dart        حفظ التقدم
  game/board.dart      منطق اللوحة: التوليد، التطابق، السقوط، الخلط، أفضل حركة
  game/levels.dart     تعريف المستويات (عدّل الأرقام هنا لتغيير الصعوبة)
  ui/symbols.dart      رسم الرموز الستة
  ui/background.dart   خلفية الصحراء والإفريز الذهبي
  ui/mummy.dart        مشهد المومياء ورسمها
  ui/game_screen.dart  شاشة اللعب والتلميحات
  ui/menu_screen.dart  القائمة واختيار المستوى
tool/setup_android.py  يضبط الاسم العربي والاتجاه العمودي بعد flutter create
.github/workflows/build.yml  بناء APK وiOS على GitHub Actions
```

## طريقة البناء

### محلياً (يلزم تثبيت Flutter 3.27 أو أحدث)

```bash
flutter create --platforms=android,ios --project-name pharaoh_match --org com.pharaohmatch .
python3 tool/setup_android.py
flutter pub get
flutter run                                   # تجربة على جهاز أو محاكي
flutter build apk --release --split-per-abi   # أندرويد
flutter build ios --release                   # iOS (يلزم جهاز Mac وحساب Apple Developer)
```

### بدون تثبيت شيء: GitHub Actions

1. ارفع المشروع إلى مستودع على GitHub.
2. مجلد `.github` مخفي فقد لا يُرفع بالسحب والإفلات. أنشئ الملف من المتصفح:
   `https://github.com/<اسمك>/<المستودع>/new/main?filename=.github/workflows/build.yml`
   والصق محتوى `build.yml`.
3. من تبويب **Actions** اختر **Build Pharaoh Match** ثم **Run workflow**.
4. بعد نحو 6 دقائق افتح التشغيل المنتهي، وفي آخر الصفحة قسم **Artifacts** نزّل
   `pharaoh-match-android` (ملف ZIP بداخله APK؛ لمعظم الهواتف الحديثة استخدم `arm64-v8a`).

ملاحظة عن iOS: الملف الناتج غير موقّع، ولا يُثبَّت على أيفون حقيقي أو يُرفع إلى
App Store إلا بعد التوقيع بحساب Apple Developer.
